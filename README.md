# Green Room Billiards

一款使用纯 HTML、CSS 和 JavaScript 制作的沉浸式物理台球网页游戏。无需安装依赖，打开浏览器即可游玩。

## 在线试玩

**[点击进入 Green Room](https://adaadame.github.io/green-room-billiards/)**

## 游戏玩法

- 移动鼠标或手指调整击球方向。
- 使用底部滑块设置击球力度。
- 点击台球桌或“击球”按钮完成击球。
- 电脑端也可以按空格键或回车键击球。
- 将 15 颗目标球全部击入六个球袋。
- 母球落袋后会在下一杆自动复位。

## 游戏特色

- 真实的球体碰撞、速度衰减与桌面摩擦
- 带能量损耗的库边反弹
- 六个球袋的入袋判定
- 标准 15 球三角形开局排列
- 实心球、花色球与号码绘制
- 可调节的击球力度
- 瞄准线与球杆视觉反馈
- 本局击球次数与进球数量统计
- 碰撞及入袋合成音效
- 音效开关与一键重新开球
- 鼠标、键盘和触摸屏操作
- 响应式桌面与手机布局

## 操作说明

| 操作 | 电脑 | 手机/平板 |
| --- | --- | --- |
| 瞄准 | 移动鼠标 | 在球桌上移动手指 |
| 调整力度 | 拖动力度滑块 | 拖动力度滑块 |
| 击球 | 点击球桌、点击按钮、空格键或回车键 | 点击球桌或“击球”按钮 |
| 重新开始 | 点击“重新开球” | 点击“重新开球” |

## 本地运行

下载 `index.html` 后直接双击，用现代浏览器打开即可。项目没有第三方资源或构建步骤，也可以完全离线运行。

## 技术实现

- HTML5 Canvas 绘制台球桌、球杆与球体
- 原生 JavaScript 实现固定时间步长物理模拟
- CSS3 构建界面、光影与响应式布局
- Web Audio API 生成轻量碰撞音效
- Pointer Events 同时支持鼠标和触摸操作
